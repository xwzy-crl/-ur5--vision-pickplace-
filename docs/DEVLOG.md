## 003：接收视觉坐标并计算接近参考点

### 修改
- 添加 target_listener.py，订阅方块世界坐标。
- 检查消息坐标系为 world。(用于判断是否为该方块的坐标命令)
- 根据方块边长计算顶面高度。
- 计算顶面上方 0.12 米处的接近参考点。

### 计算条件
方块直立，边长为 0.04 米。
顶面高度 = 中心高度 + 0.02 米。
接近参考点高度 = 顶面高度 + 0.12 米。

### 验证
运行订阅节点，检查坐标输出。
移动仿真方块，观察参考点是否同步变化。

## 004：稳定带吸盘机械臂的初始化

### 问题
加载吸盘后出现持续振动。

### 排查过程
- 确认主要控制器处于 running。
- 尝试位置接口后振动加重，已恢复力矩接口。
- 零重力启动时仍有持续振动，延长等待没有收敛。

### 修改
- 使用自己的世界文件。 code ~/catkin_ws/src/ur5_suction_lab/launch/study_scene.launch
- 物理步长从 0.001 秒缩小到 0.0002 秒。
- 暂停生成机器人，检查初始化状态后恢复正常重力。

### 验证结果
- 初始目标姿态正确。
- 最大位置误差约 0.0000073 rad。
- 最大关节速度约 0.000033 rad/s。
- 恢复重力后观察 15 秒，没有抖动。

### 验证范围
初始姿态保持通过；运动与抓取待验证。
